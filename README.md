# Student Grade Calculator

A simple Java console application that calculates a student's total marks, percentage, and grade based on marks entered for different subjects.

## Features

- Accepts the student's name
- Accepts marks for multiple subjects
- Calculates total marks
- Calculates percentage
- Assigns a grade based on the percentage
- Displays a formatted student grade report

## Technologies Used

- Java
- Java Scanner
- Arrays
- Loops
- Conditional Statements

## Subjects

The current version includes:

- Hindi
- English
- Maths
- Science
- Computer

## Grading System

| Percentage | Grade |
|------------|-------|
| 90–100     | A+    |
| 80–89      | A     |
| 70–79      | B+    |
| 60–69      | B     |
| 50–59      | C+    |
| 40–49      | C     |
| Below 40   | FAIL  |

## How to Run

1. Clone the repository.
2. Open the project in a Java-compatible IDE or VS Code.
3. Compile `Main.java`.
4. Run the program.
5. Enter the student's name and marks when prompted.
